## 📖 About This Repository

This repository houses the source code for the official landing page of **Crimson Faith**. Built to match the dark, unforgiving atmosphere of medieval zealotry and high-stakes swordplay, the site focuses on fast load times, seamless trailer playback, and direct conversion to the official **itch.io** page.

### Key Landing Page Features

- **Cinematic Hero & Official Trailer Modal:** Auto-playing background gameplay loop paired with an instant-load modal for the full **Crimson Faith** reveal trailer.
- **Combat Breakdown Showcase:** Interactive media previews highlighting core mechanics (*Deflection/Parrying, Posture Meter, Lethal Counters, Stance-Breaking*).
- **itch.io Integration:** Direct call-to-action buttons and embedded itch.io widget for immediate downloads, devlogs, and page follows.
- **Press Kit & Media Gallery:** High-resolution screenshots, transparent logos, and downloadable press assets for content creators and indie reviewers.
- **Responsive & Performant:** Optimized video formats (WebM/MP4) and lazy-loaded assets for smooth performance across desktop and mobile devices.

## ⚔️ About Crimson Faith

**Crimson Faith** is a brutal indie medieval combat game where timing, rhythm, and aggression dictate survival. Strip away button-mashing—every clash of steel carries weight. Read your opponent's stance, deflect incoming strikes to shatter their posture, and execute a decisive fatal blow.

- **Genre:** Action / Sekiro-like / Medieval Swordplay
- **Platform:** PC (Exclusively on **itch.io**)
- **Status:** In Development / Trailer Coming Soon
